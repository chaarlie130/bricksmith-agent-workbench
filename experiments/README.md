# Archived experiments

[`legacy/`](legacy/) contains earlier architectural model drafts, generator
scripts, and one-off repair helpers. Their original contents are preserved,
including paths tied to the old layout. To reproduce one of those runs, start
from the [pre-archive checkout](https://github.com/chaarlie130/bricksmith-agent-workbench/tree/cf7f977619ce31bc4feee0f6271e483e8b199c0d).
For supported command entry points, see the [command guide](../docs/AGENT_WORKBENCH.md).
