# Reference data and part libraries

[`reference_sets/`](reference_sets/) contains LDraw reference models and a
[provenance manifest](reference_sets/manifest.json). The workbench uses these
models for search and design study. Check the recorded source and license
before reusing or distributing any third-party model. Historical stability
scores describe their source pipeline.

[Configure the local libraries](../docs/SETUP.md#configure-the-part-libraries)
before checking or rendering a model. `data/ldraw` points to your LDraw parts
library. `data/bricknet-data` is a local directory or link for BrickNet meshes.
Both paths are ignored by Git.
